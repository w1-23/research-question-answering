# CitrusScholar capability migration

Source reference is CitrusScholar `d275430d3ef01bf9558ccd85204d1bdede631989`. The method is an independent Agent Skill. This document describes a host binding to existing capabilities.

| Role | Baseline binding | Adapter behavior |
| --- | --- | --- |
| Local discovery | `local_hybrid_search` or `search_candidates`; `inspect_candidates` for an already populated pool | Use the request's permitted corpus scope. Preserve `None` as all authorized corpora and `[]` as none. Reuse equivalent prefetched candidates through the host when available. For a new query choose one local path, cap the results, and project its public candidate preview and stable `source_ref`, `read_entry`, `document_key`, `locator`, `query_ref` and generation. Keep base versus shared identity and generation under the host's original locator and authorization rules. |
| Local excerpt and history | `read_candidate(candidate_id, offset, max_chars, turn_id, generation)` | Use `candidate_id`, `turn_id` and `generation` from the original `read_entry`. The stable `ev:` path uses `read_local_evidence` and can resolve after restart. Project the authoritative artifact `source` and `text`, echo the verified original read entry and preserve its generation and excerpt offsets. For legacy `cNN` aliases the host needs the live pool. On expired or revoked evidence, return `expired` or `denied` with no replacement search. |
| Web discovery | `deepseek_search(query, count, need_content=False)` | Use `web_results` as candidate leads. Distinguish disabled, timeout and provider failures even when the result list is empty. The baseline has tool text markers for several such cases. A generated summary cannot become a citation excerpt. |
| Selected web evidence | `deepseek_fetch(url)` | Fetch the one selected authorized URL if its text is needed. Use the existing guarded Fetch path and persist the exact permitted excerpt and original source identity through the host's evidence path before returning `Evidence`. History must resolve the stored excerpt. The adapter can return `unavailable` when durable web excerpts are unsupported. |
| User file, Code and deliverable | `read_account_file`, native `read_file` on its permitted mount, existing guarded Code runtime, `deliver_research_artifact` or the ordinary answer | Keep these capabilities in the host. A permitted file excerpt can be projected as `Evidence(origin="file", ...)` when the host supplies a durable ref. Use Code or publication only for a user goal that needs them. |
| Citation display | Existing `turn_source_ledger` and source reader UI | The package returns stable adopted `source_ref` values and never creates user-facing local/web labels. Project bubbles from those refs in the host, using the saved record and exact excerpt, its URL or original local locator. Keep candidates and delivered excerpts distinct from adopted citations. |

Keep the effective research scope and dual-route decision in the host. On a knowledge subgoal with insufficient permitted evidence, the product policy may supply both authorized routes. On translation, attachment plotting, format conversion and other subgoals that can operate on supplied input, it supplies no research route. In a mixed task apply source policy to each subgoal. Installing or disabling this Skill changes method exposure only. Underlying tool exposure and execution policy are configured separately.

`search_local_candidates` is a baseline internal rows helper. Use the callable host boundary that has already scoped and persisted evidence when exposing candidates to the Skill. The Skill receives only permitted excerpts and bounded previews. It imports neither Citrus code nor query/index implementations.

## Integration work to verify in the parent repository

- Bind the public dispatcher or its structured receipts to `Discovery` and `ReadResult`. Verify local `partial` and maintenance outcomes, provider empty versus error outcomes, and the task-level Search/Fetch/RAG switches including prefetch and existing cache access.
- Pass an equivalent cached `Discovery` through `discover(..., reuse=...)` only when the host has proved query purpose, scope, file and index generation, ranking and permission equivalence. Confirm the reused route callback is not invoked.
- The baseline Fetch row carries URL and body without a durable excerpt `source_ref` in its shown result shape. The baseline ledger projects sources from tool rows by local record key or URL. Verify or complete host-owned durable web excerpt storage and exact cited-ref-to-bubble projection for base, shared and web sources. Verify readback after restart, index swap and revocation against the same original refs.
- Check Skill off with the same tools, per-subgoal routing, source-policy isolation, the real main model and the final Worker. The independent tests exercise synthetic callback and portability contracts. Product acceptance requires the integrated build.
